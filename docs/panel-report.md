# Fixed-panel validation API

`joey_research.panel_report.panel_report(inputs: bytes, labels: bytes, arms: Mapping[str, ArmRun], *, split: str, inputs_sha256: str, labels_sha256: str, pairs: Sequence[Pair], diagnostics: Mapping[str, Sequence[tuple[int, str]]] | None = None) -> dict`

Supply one authorized `selection` or `discovery` shard as its exact JSONL bytes, with labels in **identical ID/digest order**. Obtain the two SHA-256 pins from independent split/label custody. Never hash a reconstructed or freshly joined subset and call it verified. This API neither releases labels nor checks the original custody chronology.

Each `ArmRun(packet, predictions, trace, complete, pins, slot, permit_sha256=None)` takes four original byte streams. The `pins` map has exactly `packet.json`, `predictions.jsonl`, `trace.jsonl`, `complete.json`: use independently verified admission/transport receipts, not self-asserted digests. For selection also pass the verified permit hash. The host supplies an opaque same-slot token, or `None` if unverified; it is not inferred from model/device names or emitted in the report.

`Pair(name, baseline, candidate, kind="contrast")` fixes direction: all deltas are candidate minus baseline. Special kinds are `matched_path` (zero-extra split baseline, same window/model/order recurrence candidate), `order_ensemble` (one side has a verified whole-group second-order budget), and `compact_vs_stock` (full stock baseline, verified physically compact candidate). Example diagnostic specification: `{"recorded_arm": [(1, "first_pass"), (2, "iterate")]}`. The report projects each recorded readout into original option order as emitted by the worker; it does not retime it or infer savings.

`arms` reports scores, risk/coverage with whole ties, invalid IDs, and confident-error numerators/denominators at 0.8/0.9/0.95/0.99. `pairs` reports corrections/corruptions and pointwise 95% intervals from 2,000 shared task-stratified group resamples for each named contrast. Undefined rates/intervals are `null` with support/status, never evidence of zero harm. Under `compact_vs_stock` only, noninferiority requires **both** lower macro accuracy delta bound `> -0.02` and upper macro Brier delta bound `< 0.01`, with valid predictions and defined intervals. No ranking, multiple-comparison correction or automatic winner selection is performed.

Compute totals include the block and coda inside each opaque stock call; order-ensemble callbacks and layers are already summed, not multiplied again. `compute.per_decision` retains ID-bound measurements for private analysis. CUDA and synchronized wall times are milliseconds per measured decision (`mean`, nearest-rank `50/95/99`, `total`); memory is measured peak allocated bytes. A candidate/baseline mean CUDA-time ratio in `[0.90, 1.10]` on the **same independently verified A100 slot** satisfies a measurement criterion, not evidence of equal hardware efficiency. Unknown/different slots or zero baseline time leave that comparison unevaluable. Malformed joins, mixed splits, mismatched pins, absent passes, inconsistent group spend or telemetry raise errors; no partial rejoin is attempted.
